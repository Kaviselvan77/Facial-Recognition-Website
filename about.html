PROJECT NOTES

How FaceScope works

A small educational web app demonstrating a classic computer-vision pipeline.

01

Detect

OpenCV Haar Cascade locates likely face regions in the uploaded image.

02

Preprocess

The selected face crop is converted to grayscale and resized to 160 × 160 pixels.

03

Recognize

LBPH compares the crop against enrolled training examples. A distance threshold determines whether to show a known label or Unknown.

04

Evaluate

Run the evaluation script on separate test images to report measured accuracy and classification metrics.

Limitations & responsible use

This demo is not suitable for security or consequential decisions. Lighting, pose, occlusion, image quality, and dataset size can affect results. The LBPH distance is not a calibrated confidence probability. Obtain informed consent before collecting or processing anyone's face images, and do not publish private images or model files.
